# MyMoney 1.0.0-rc.2

Bug-fix update. Install `MyMoney-1.0.0-rc.2.apk` over rc.1; your data stays (same signing key).

## Fixed
- **Save is always visible in editors.** Account, transaction, budget, recurring bill, goal, asset and debt
  forms had Save only at the end of a long form, often below the screen or under the keyboard, so adding a
  second account looked impossible. Save is now also in each editor's top bar.
- **Search field position.** The search field sat under the status bar and the selfie camera; it now starts
  below the status bar like every other screen.

## Notes
- Because this developer key is new to Google, Play Protect may say "App blocked to protect your device";
  tap **Install anyway** (not "Got it").
