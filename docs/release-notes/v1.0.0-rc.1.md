# MyMoney 1.0.0-rc.1

First release candidate. Install `MyMoney-1.0.0-rc.1.apk` on Android 8.0+ (tap the file, allow
"Install unknown apps" when asked).

## What's inside
- Accounts, transactions (splits, transfers between currencies, refunds), budgets, recurring bills and
  subscriptions, debts and receivables, assets, savings goals.
- 13 reports, local insights, month-end estimate.
- Jalali/Gregorian calendars, Persian/English, exact rial/toman.
- PIN + fingerprint lock, encrypted database and receipts, no internet permission.
- Encrypted backup/restore, CSV import, CSV/JSON/PDF export.
- Liquid-glass design (can be turned off in Settings).

## Notes
- Signed with the author's development key: fine for installing and sharing; updates must come from the same
  source.
- Verified on Samsung Galaxy A55 (Android 16). Full list of changes: CHANGELOG.md.
